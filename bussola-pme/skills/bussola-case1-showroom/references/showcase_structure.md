# Estrutura de Showcase — Bússola PME

## Formato de 7 Slides (Deck comercial)

| Slide | Nome | Conteúdo | Objetivo |
|-------|------|----------|----------|
| 1 | Problema | Situação da empresa antes do método | Empatia com prospect |
| 2 | Antes | Métricas e sintomas do problema | Concretizar a dor |
| 3 | Método | Visão geral da abordagem Bússola PME | Diferenciar |
| 4 | Amostra | Print ou extrato de artefato real (anonimizado) | Prova de processo |
| 5 | Métricas | Resultados obtidos (arredondados ±5%) | Prova social quantitativa |
| 6 | Testemunho | Citação do cliente (anonimizada) | Credibilidade |
| 7 | CTA | Próximo passo para o prospect | Conversão |

## Showcase Interativo (LinkedIn / Landing)

### Seções obrigatórias

```
[Header]         → Logo + tagline
[Situação]       → Parágrafo problema central
[Diagnóstico]    → 3 achados chave (bullet cards)
[Ações]          → Top 3 iniciativas implementadas
[Resultados]     → Métricas com barras visuais
[Método]         → Infográfico das 6 fases
[CTA]            → Botão "Quero uma sessão diagnóstico"
```

### Adaptações por canal

| Canal | Ajuste principal | Tom | CTA |
|-------|-----------------|-----|-----|
| LinkedIn | Texto ≤ 3 parágrafos + visual | Profissional reflexivo | "Reconhece esse cenário?" |
| Landing page | Copy longo + depoimento | Consultivo direto | "Agendar diagnóstico" |
| WhatsApp (one-pager) | PDF 1 página, visual limpo | Direto e concreto | Link WhatsApp |
| Sales call deck | 7 slides, pouco texto | Executivo | Discussão presencial |

## Requisitos de Anonimização

- **Nomes de empresa** → Sempre substituídos por segmento genérico ("Agência B2B de comunicação")
- **Nomes de pessoas** → Sempre substituídos por nomes fictícios genéricos (não regionais)
- **Métricas** → Arredondadas para ±5% (ex: 43% → "~40–45%")
- **Datas** → Aproximadas para trimestre (ex: "março 2025" → "Q1 2025")
- **CNPJ/CPF** → Removidos completamente
- **Endereços** → Removidos ou substituídos por cidade genérica
- **Dados financeiros** → Arredondados para faixa (ex: R$ 960k → "~R$ 900k–1M")
