# Módulo: 5W2H

## Quando usar
- Plano de ação existente mas com baixa especificidade de execução
- Ações definidas mas sem clareza de responsabilidade, prazo, ou método
- Equipe precisa de instruções claras para executar sem depender do consultor
- **Sinal trigger**: "como executar", "o que fazer exatamente", "quem é responsável", "plano pouco detalhado"

## Inputs necessários
- Lista de ações do plano (da Sub-fase 5)
- `deliverable_depth == deep` no consultant_config.yaml (para ativar 5W2H completo)
- Owner e deadline já definidos (campos obrigatórios do plano)

## Campos do 5W2H

| Campo | Pergunta | Descrição |
|-------|----------|-----------|
| What | O quê? | Ação específica a ser executada |
| Why | Por quê? | Justificativa ligada ao problema diagnósticado |
| Where | Onde? | Local, sistema, processo, ou equipe afetada |
| When | Quando? | Deadline e marcos intermediários |
| Who | Quem? | Owner principal + stakeholders envolvidos |
| How | Como? | Método, ferramentas, passos de execução |
| How Much | Quanto? | Investimento necessário (tempo, R$, recursos) |

## Processo de aplicação

1. Para cada ação do `plano_acao.md`, preencher os 7 campos
2. Verificar consistência interna (Who ↔ When, How ↔ How Much)
3. Cruzar com `priority_score.md` para confirmar alinhamento
4. Executar `action_field_enforcer.py --depth deep` para validação

## Output esperado

```markdown

| Campo | Conteúdo |
|-------|----------|
| **What** | Revisar e documentar Ideal Customer Profile (ICP) da agência |
| **Why** | ICP desatualizado é hipótese de causa raiz da queda de pipeline [HIPÓTESE] |
| **Where** | Documento de ICP (Notion/Google Docs) + dados do CRM (HubSpot) |
| **When** | Entrega em 2026-05-01; review intermediário em 2026-04-24 |
| **Who** | Owner: Marina Costa; apoio: Rafael Lima (dados CRM) |
| **How** | 1) Exportar dados de clientes atuais 2) Identificar top 5 por LTV 3) Entrevistas curtas (20min) 4) Documentar padrões |
| **How Much** | 8h de Marina + 2h de Rafael; custo de entrevistas: zero (clientes atuais) |
```

## Template de saída

```yaml
action_id: "string"
action_name: "string"
5w2h:
  what: "string"
  why: "string [label]"
  where: "string"
  when: "string ISO8601 ou descrição de prazo"
  who: "string — owner + stakeholders"
  how: "string — passos ou método"
  how_much: "string — tempo, R$, recursos"
```

## Limitações

- **Overhead**: 5W2H tem custo de preenchimento; usar apenas quando deliverable_depth=deep
- **Não substitui diagnóstico**: Define como executar, não por que executar
- **Qualidade do How**: Depende do conhecimento do cliente sobre seus próprios processos
- **Não use** para ações de alto nível estratégico (use para ações operacionais específicas)
